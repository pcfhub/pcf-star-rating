## What changed

Nothing you can see. The clear button's ✕ is now set as text rather than
parsed as HTML, so the control writes no HTML anywhere. It is the same
character in the same place.

This release is also the first built with the control's test suite running in
the build: 40 checks against the built bundle, including the right-to-left
arrow keys, the half-step rule for a whole-number column, a colour value that
must not reach the page, and clearing a canvas field (which needs `null`, not
"no change"). The four demo presets draw as before.

## What you must do

Nothing. Upgrading from 0.1.2 changes no property, no default and no
behaviour.
